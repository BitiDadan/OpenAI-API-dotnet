# 提尔之手 / Tyr's Hand

国服魔兽世界正式服插件诊断助手，版本 0.1.0。

## 安装与使用

1. 将整个 `TyrsHand` 文件夹复制到国服客户端的 `_retail_/Interface/AddOns/` 下。
2. 当前 TOC 的 `Interface: 120000` 是临时兼容基线，尚未核对国服版本。在游戏运行 `/dump GetBuildInfo()`，将 TOC 中的数字改为返回的第四项。也可临时勾选“加载过期插件”；这不保证 API 兼容。
3. 登录后输入 `/tyr` 或 `/tyrshand`，打开报告窗口。
4. 复现错误，再点击“刷新报告”，点击文本并按 Ctrl+A、Ctrl+C 复制。
5. 分享前检查报告是否含个人信息。点击“清空错误”可删除已保存的错误记录。

插件保留最近 50 条错误，相邻相同错误合并计数；报告显示最近 20 条。正常退出或重载界面时，由游戏保存到 SavedVariables。异常退出可能丢失本次记录。

## 范围与限制

- 收集本插件加载后的 Lua 错误、调用栈、客户端版本及当前插件清单。不能捕获加载前错误，也不能检查任意磁盘文件、崩溃或其他插件的私有局部变量。
- 不修改其他插件控件、不自动禁用插件、不绕过战斗保护，也不自动向外发送报告。
- 保留并调用原有错误处理器。其他错误收集插件可能随后替换处理器；报告会显示当前挂接状态。不能保证与所有错误收集器兼容。
- 调用栈是线索，不是冲突结论。建议先保留提尔之手及必要依赖，再对其余插件分批启用，每次 `/reload` 后复现。不能在诊断过程中随意删除 SavedVariables。
- 云端测试使用模拟 API；真实国服 UI、受保护值、污染与战斗状态仍需客户端实测。

## 开发

```bash
source /workspace/.wow-tools/activate.sh
cd /workspace/TyrsHand
luac -p Core.lua Main.lua
luacheck Core.lua Main.lua
lua tests/run.lua
```

Lua 5.1 是语法与离线测试基线，不是完整的 WoW Lua 运行时。API 应以目标客户端导出的 Blizzard 文档和实际行为为准。
